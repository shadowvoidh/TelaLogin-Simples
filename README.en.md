A modern, responsive, and minimalist web application divided into two main stages: an interactive **Login Screen** with custom validations and a *Glassmorphism*-style **Links Hub** with a light theme and modern visual effects.

---

## 🎨 Demo & Features

### 🔐 1. Login Screen (`index.html`)
- **Custom Validation:** Handles email errors and empty fields with elegant visual feedback without relying on the browser's native tooltips.
- **Micro-interactions:** Dynamic login button featuring a *loading* state (CSS spinner animation) and click-prevention while submitting.
- **Toast Notification:** "Login Approved" alert sliding smoothly across the screen before redirection.
- **Password Toggle:** Show/hide password feature.
- **Adaptive Layout:** Dual-panel layout with desktop illustration that turns into a single column on mobile screens.

### 🌐 2. Links Hub (`dashboard/dashboard.html`)
- **Glassmorphism Design:** Translucent cards over a light background with blurred purple background effects (*glow blobs*).
- **Social Icons:** Integrated links for GitHub, Instagram, LinkedIn, and repositories.
- **Fully Responsive:** Fluid layout tailored for smartphones, tablets, and desktops.
